# XAU/USD & SJC Radar (Web App Tích sản Vàng)

Ứng dụng web phân tích, dự báo giá vàng đa khung (D1/W1), sổ tay giá vốn theo từng lần mua, đèn tín hiệu tích sản, lộ trình tăng tỷ trọng và kiểm thử chiến lược 10 năm — sẵn sàng cài đặt ra màn hình chính (PWA) trên iPhone, Android và máy tính.

## Cách đưa lên GitHub Pages (miễn phí trong 2 phút)

1. Giải nén tệp `vang-radar-github-pwa.zip`.
2. Tạo một repository mới (Public) trên GitHub (ví dụ: `vang-radar`).
3. Chọn **Add file → Upload files**, kéo thả toàn bộ các tệp bên trong thư mục (`index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon.svg`, `README.md`) lên và nhấn **Commit changes**.
4. Vào **Settings → Pages** → mục **Branch** chọn `main` và `/ (root)` → nhấn **Save**.
5. Đợi khoảng 1 phút, GitHub sẽ cấp đường dẫn dạng `https://<ten-tai-khoan>.github.io/vang-radar/`.

## Cách cài ra Màn hình chính điện thoại

- **iPhone / iPad (Safari):** Mở đường dẫn GitHub Pages bằng Safari → chạm nút **Chia sẻ (↑)** → chọn **Thêm vào MH chính (Add to Home Screen)** → nhấn **Thêm**.
- **Android (Chrome):** Mở đường dẫn bằng Chrome → chạm menu **⋮** → chọn **Cài đặt ứng dụng / Thêm vào màn hình chính**.
